## v0.2.0

### Features

- Add reusable branding asset generator.
- Add richer gamepad support, metadata, calibration and visual probing.
- Add dynamic framebuffer presentation sizing and adaptive nearest-neighbour presentation.
- Add reusable pixel game hosting support.
- Add outline font fallback stacks and mixed-script fallback metadata.
- Add language metadata, procedural flags and reusable icon/text UI primitives.
- Add CJK validation support and script-aware raster policy.
- Add supersampled outline text rendering.
- Advance GPE.UI interaction, spatial layout and runtime validation.
- Add shareable Web graphics diagnostics and query-parameter activation.

### Bug Fixes

- Improve gamepad calibration and controller visual probe accuracy.
- Forward child tool-window hooks through pixel game hosting.
- Distinguish missing bitmap glyphs from literal question marks.
- Fix locale/native-language text resolution.
- Harden UI semantic output and module exports.
- Improve fullscreen behavior, aspect-ratio preservation and legacy Web canvas sizing.

### Performance

- Complete GPE.UI MFE-001C runtime and cost validation.

### Documentation

- Document repository ownership boundaries and branding tooling.
- Document standalone Pages deployment constraints.
- Record GPE.UI productionization milestones and diagnostics guidance.
