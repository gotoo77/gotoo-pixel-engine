# Void Canticle — Pilgrim concept sheet v1

**Status:** direction artistique validée — 18 août 2026  
**Gameplay:** shmup à scrolling vertical, déplacement et tirs vers le haut.

![Pilgrim concept sheet](pilgrim_concept_sheet_v1.jpg)

## Direction retenue

Le Pèlerin doit être lu immédiatement comme **un humanoïde en exo-armure / scaphandre liturgique**, jamais comme un vaisseau.

La direction retenue mélange principalement :

- **Iron Pilgrim** : masse d'armure, épaules, lisibilité mécanique, cœur énergétique ;
- **Scaphandre liturgique** : casque/reliquaire, silhouette rituelle, halo, accents violet/or ;
- quelques éléments de l'**Ange mécanique** peuvent être réservés à des évolutions, pouvoirs ou états exceptionnels, mais les ailes ne font pas partie de la silhouette gameplay de base.

## Règle de caméra / orientation

- **Vue avant** : présentation de stage, briefing, écran de victoire, codex, portrait, illustration narrative.
- **Vue arrière ou 3/4 arrière** : gameplay normal.
- Le Pèlerin remonte l'écran ; son attaque principale est donc émise **verticalement vers le haut**.
- Les poses de tir latérales / profil ne sont pas une référence gameplay pour Void Canticle.

## Silhouette gameplay

La petite silhouette doit rester humanoïde même à très basse résolution :

- casque clairement séparé du torse ;
- épaules marquées ;
- deux bras identifiables ;
- backpack / reliquaire dorsal ;
- Braise Stellaire visible ;
- deux jambes séparées ;
- propulsion dorsale et/ou sous les pieds ;
- aucune pointe frontale pouvant être lue comme le nez d'un chasseur spatial.

## Focus

Maintenir **Shift** :

- posture resserrée ;
- déplacement plus lent et précis ;
- hitbox centrale explicitement visible ;
- halo / géométrie rituelle renforcée ;
- silhouette toujours lisible sous les projectiles.

## Tir principal

Le tir remonte l'écran. Selon le niveau de puissance, il peut visuellement provenir :

- du Cœur Stellaire / torse ;
- des mains / avant-bras ;
- de petits émetteurs d'épaule.

Les variations de niveau d'arme doivent élargir et renforcer la volée sans transformer le personnage en « vaisseau avec canons ».

## Palette de travail

- ivoire / os : armure principale ;
- graphite / bleu-noir : joints, backpack, ombres ;
- or vieilli : détails liturgiques ;
- violet : énergie rituelle / Focus / reliques ;
- orange : Braise Stellaire et accents thermiques.

Cette planche reste une **référence de direction**, pas un sprite final. Les assets définitifs seront produits à l'échelle réelle du jeu puis validés en mouvement et dans le chaos des patterns.
