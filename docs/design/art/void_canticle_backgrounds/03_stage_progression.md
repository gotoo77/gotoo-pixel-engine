# 2. Bibliothèque des environnements VC

Les fonds explorés peuvent déjà constituer une première bibliothèque de biomes.

## 2.1 BLUE SILENCE

**Asset actuel :** `ruines_cosmiques_dans_la_brume_bleue.png`

### Identité

- bleu froid ;
- obscurité ;
- grandes ruines verticales ;
- sensation de distance et de silence.

### Usage

Excellent environnement d’ouverture.

Il laisse au joueur le temps de comprendre l’univers sans provoquer immédiatement une saturation visuelle.

### Gameplay

Très bon candidat pour :

- premières vagues ;
- apprentissage de lecture ;
- patterns simples ;
- combat dense plus tard, grâce à son faible bruit visuel.

---

## 2.2 VOID / ABYSS

**Asset actuel :** `ruines_cosmiques_sous_l_œil_violet.png`

### Identité

- violet très sombre ;
- singularité / œil cosmique ;
- structures monumentales périphériques ;
- grand vide central.

### Usage

Environnement iconique de VC.

Il introduit l’idée que le Void n’est peut-être pas uniquement un lieu.

### Gameplay

Très bonne lisibilité.

Le halo supérieur peut devenir un landmark persistant tandis que le centre reste sombre.

---

## 2.3 DEAD EMPIRE

**Asset actuel :** `a_dramatic_dark_sci_fi_space_scene_in_a_tall_vert.png`

### Identité

- ruines orbitales ;
- structures fracturées ;
- planète ;
- traces d’un empire disparu.

### Usage

Premier stage où l’univers raconte clairement qu’une civilisation a existé.

### Gameplay

Demande une réduction du détail central. Les grosses masses doivent rester latérales ou très éloignées.

---

## 2.4 GRAVEYARD

**Asset actuel :** `a_dramatic_sci_fi_space_scene_a_vast_deep_space_v.png`

### Identité

- cimetière orbital ;
- épaves ;
- débris ;
- vortex / phénomène lumineux ;
- forte sensation de catastrophe ancienne.

### Usage

Stage de milieu de campagne, plus chaotique.

### Gameplay

C’est le meilleur candidat pour extraire une partie des débris de l’image fixe et les transformer en couches animées indépendantes.

---

## 2.5 TOXIC CANTICLE

**Asset actuel :** `a_highly_detailed_sci_fi_space_scene_vertical_com.png`

### Identité

- vert / cyan ;
- portail ou phénomène énergétique ;
- structures étrangères ;
- environnement actif.

### Usage

Changement chromatique majeur.

Le joueur comprend que le Void possède différentes « zones » ou états.

### Gameplay

La version production doit assombrir le centre et concentrer le vert vif dans :

- les fissures ;
- le portail ;
- certains halos ;
- les périphéries.

---

## 2.6 ASHEN EMPIRE

**Asset actuel :** `ruines_cosmiques_sous_un_soleil_noir.png`

### Identité

- noir ;
- gris ;
- métal mort ;
- braises orange ;
- soleil noir / éclipse.

### Usage

Zone oppressive et tardive.

### Gameplay

Très bon matériau naturel pour un SHMUP : faible saturation, contrastes localisés.

---

## 2.7 BLOOD CANTICLE

**Asset actuel :** `cathédrale_cosmique_en_ruines.png`

### Identité

- carmin ;
- rouge sombre ;
- structures liturgiques ;
- catastrophe / rituel.

### Usage

Pré-climax.

Le changement de palette doit signaler immédiatement qu’une limite a été franchie.

### Gameplay

Le rouge brillant doit rester périphérique. Le corridor central doit être bordeaux / noir très sombre.

---

## 2.8 ECLIPSE

**Asset actuel :** `mégastructures_oubliées_sous_une_éclipse_violette.png`

### Identité

- éclipse violette ;
- anneaux monumentaux ;
- mégastructures ;
- verticalité ;
- sentiment de révélation.

### Usage

Fin de chapitre, climax ou approche du boss final.

### Gameplay

Le landmark principal peut rester spectaculaire dans le tiers supérieur, tandis qu’un gouffre visuel sombre s’ouvre sous lui.

---
