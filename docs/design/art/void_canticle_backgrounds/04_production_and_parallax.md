# 3. Progression visuelle proposée

La progression ne doit pas seulement augmenter la difficulté. Elle doit faire évoluer :

- la couleur ;
- la densité ;
- la signification des structures ;
- le niveau de menace ;
- le degré de « sacré » ou d’anormalité.

---

## Acte I — Découverte

### Stage 1 — BLUE SILENCE

**Fonction :** entrée dans le Void.

Sensation :

- silence ;
- solitude ;
- immensité ;
- beauté froide.

Boss possible :

- sentinelle ;
- éclaireur du Void ;
- drone liturgique.

---

### Stage 2 — VOID / ABYSS

**Fonction :** première anomalie majeure.

Sensation :

- le Void semble regarder le joueur ;
- les structures cessent d’être de simples ruines ;
- une présence est suggérée.

Boss possible :

- gardien de faille ;
- entité orbitale.

---

## Acte II — Constat de ruine

### Stage 3 — DEAD EMPIRE

**Fonction :** révélation d’une civilisation disparue.

Sensation :

- territoire ancien ;
- architecture ;
- empire mort ;
- catastrophe passée.

Boss possible :

- croiseur réanimé ;
- autel de guerre orbital.

---

### Stage 4 — GRAVEYARD

**Fonction :** montrer les conséquences de la catastrophe.

Sensation :

- chaos ;
- épaves ;
- tombes mécaniques ;
- champ de bataille fossilisé.

Boss possible :

- forteresse-épave ;
- charognard cosmique.

---

## Acte III — Contamination / révélation

### Stage 5 — TOXIC CANTICLE

**Fonction :** rupture visuelle et conceptuelle.

Sensation :

- énergie interdite ;
- environnement vivant ou actif ;
- physique différente.

Boss possible :

- oracle énergétique ;
- prêtre-moteur ;
- cœur irradié.

---

### Stage 6 — ASHEN EMPIRE

**Fonction :** entrer dans une zone consumée.

Sensation :

- monde mort ;
- métal fossilisé ;
- oppression ;
- silence lourd.

Boss possible :

- titan noir ;
- juge du Void ;
- relique industrielle.

---

## Acte IV — Liturgie finale

### Stage 7 — BLOOD CANTICLE

**Fonction :** pré-climax rituel.

Sensation :

- sacrifice ;
- violence ;
- cathédrale ;
- apocalypse.

Boss possible :

- hiérophante ;
- ange-machine ;
- arche vivante.

---

### Stage 8 — ECLIPSE

**Fonction :** révélation monumentale.

Sensation :

- transcendance ;
- architecture cosmique ;
- mythologie devenue tangible.

Boss possible :

- cœur du Canticle ;
- dieu-machine ;
- singularité consciente ;
- cathédrale vivante.

---

## Courbe chromatique

```text
BLEU FROID
    ↓
VIOLET / ABYSSAL
    ↓
RUINES / MÉTAL
    ↓
CHAOS / CIMETIÈRE
    ↓
VERT TOXIQUE
    ↓
NOIR / CENDRE
    ↓
ROUGE / RITUEL
    ↓
VIOLET / ÉCLIPSE
```

La boucle chromatique finale vers le violet permet de revenir à l’identité fondatrice de VC, mais à une échelle beaucoup plus monumentale.
