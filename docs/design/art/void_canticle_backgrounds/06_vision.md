# 10. Vision finale

Void Canticle doit créer un contraste volontaire :

**au premier plan :**

- sprites ;
- tirs ;
- patterns ;
- gameplay précis ;
- lisibilité immédiate.

**au second plan :**

- immensité ;
- ruines ;
- anomalies ;
- silence ;
- structures impossibles ;
- cosmologie.

Le joueur pilote un petit appareil précis au milieu de choses qui semblent exister depuis des millions d’années et dont il ne comprend pas encore la fonction.

Le background ne doit donc pas être un simple décor.

Il doit être la première manière dont **le Void raconte son histoire**.
