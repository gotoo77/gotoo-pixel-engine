# Void Canticle — Product Vision

## North Star

**Void Canticle a vocation à devenir un action-roguelite à progression incrémentale, immédiatement lisible mais offrant une profondeur de maîtrise très importante.**

Le cœur du jeu reste l’action : déplacement, esquive, positionnement, gestion des menaces, exploitation des synergies et construction progressive d’un build pendant chaque run. Le joueur doit pouvoir comprendre les bases en quelques secondes, commencer à s’amuser immédiatement, puis découvrir progressivement toute la profondeur du système : **easy to discover, hard to master**.

## Progression pendant une run

La montée en puissance doit être visible, régulière et de plus en plus spectaculaire.

Les ennemis donnent de l’expérience et des récompenses physiques dans le monde. Une barre d’XP suit une courbe de progression de plus en plus exigeante, dans l’esprit des ARPG : les premiers niveaux arrivent rapidement, puis chaque niveau demande davantage d’investissement.

Chaque montée de niveau devient une décision de build :

- nouvelle capacité ;
- amélioration d’une capacité existante ;
- mutation d’un comportement ;
- spécialisation ;
- synergie avec un choix précédent.

La trajectoire émotionnelle recherchée pendant une run est :

**fragile → dangereux → puissant → monstrueux → presque incontrôlable**.

Le joueur doit régulièrement ressentir : « encore un niveau et mon build va décoller », puis « ça marche vraiment », puis « je veux voir jusqu’où je peux pousser cette combinaison ».

## Loot physique et champ magnétique

Les ennemis lâchent expérience, ressources, fragments, or ou autres récompenses sous forme d’objets visibles dans le monde.

Le Pèlerin possède un **champ d’attraction magnétique** qui permet de récupérer ces éléments à distance. Sa portée et son efficacité peuvent évoluer pendant la run.

L’aspiration du loot n’est pas seulement utilitaire : elle doit être un plaisir sensoriel. Nettoyer une zone, laisser l’écran se couvrir de récompenses, puis attirer brutalement tout le butin vers le joueur doit devenir un moment satisfaisant à part entière.

## Exploration et mondes

Void Canticle ne doit pas devenir une simple arène infinie.

Les runs doivent donner le sentiment d’explorer un univers composé de mondes et de zones distinctes. Le joueur découvre de nouveaux secteurs, atteint des **Warpgates**, ouvre des passages et accumule certaines ressources persistantes nécessaires à l’accès à de nouveaux environnements.

Chaque monde peut introduire ses propres :

- ennemis ;
- boss ;
- hazards ;
- règles locales ;
- ressources ;
- possibilités de build ;
- identité audiovisuelle.

## Méta-progression

La progression persistante doit **élargir l’espace des possibilités**, pas seulement augmenter les statistiques.

Un arbre de talents, des armes, archétypes, capacités et synergies peuvent être progressivement débloqués. L’objectif n’est pas simplement de faire plus de dégâts, mais de disposer d’un espace de construction de build de plus en plus riche.

La méta-progression doit permettre de :

- découvrir de nouvelles interactions ;
- ouvrir de nouveaux styles de jeu ;
- spécialiser le Pèlerin ;
- construire des builds volontairement extrêmes ;
- accéder à de nouveaux mondes et systèmes.

## Boucles imbriquées

Boucle principale :

**combat → loot → XP → choix de build → puissance → exploration → Warpgate / boss → ressources persistantes → nouveaux accès / nouveaux systèmes → nouvelle run**

Boucle d’une run :

**combat → XP → level-up → choix → synergie → montée en puissance → boss**

Boucle long terme :

**runs → ressources persistantes → nouveaux talents / armes / archétypes → nouveaux mondes → nouvelles mécaniques → nouveaux builds**

## Ambition audiovisuelle

Void Canticle ne doit pas rester une démonstration technique GPE avec beaucoup de systèmes.

L’objectif est une identité audiovisuelle forte :

- pixel art extrêmement travaillé ;
- animations généreuses ;
- particules et impacts lisibles ;
- explosions de loot ;
- shaders et effets de matière lorsque GPE le permettra ;
- musique agressive, liturgique, industrielle et évolutive ;
- sound design massif ;
- transitions et interface fortement polies ;
- feedback précis sur les dégâts, esquives, pickups et changements de phase.

Chaque action importante doit avoir du poids.

## Positionnement

> **Void Canticle est un action-roguelite frénétique d’exploration et de construction de builds, dans lequel chaque run transforme progressivement le joueur d’une présence fragile perdue dans le Void en une anomalie capable de ravager l’écran entier. Les runs permettent d’explorer des mondes, franchir des Warpgates et débloquer durablement de nouvelles possibilités, tandis qu’un système profond de talents, capacités et synergies encourage l’expérimentation. Accessible immédiatement, spectaculaire rapidement, mais conçu pour révéler sa profondeur sur des dizaines d’heures : easy to discover, hard to master.**

Les références d’intention peuvent évoquer Vampire Survivors pour le plaisir de l’aspiration du loot, Diablo pour la montée d’XP et la construction de puissance, Hades pour la lisibilité des choix de run et les roguelites d’action pour la rejouabilité — sans chercher à copier leur structure.

## Règle constitutionnelle

**La progression incrémentale doit toujours débloquer davantage de jeu, jamais se substituer au jeu.**

Autrement dit :

- la progression doit enrichir les décisions du joueur ;
- ou amplifier la satisfaction de ses actions ;
- ou ouvrir de nouvelles possibilités de jeu.

Si un système ne fait qu’allonger une barre ou ajouter un bonus numérique sans créer de décision, de sensation ou de possibilité nouvelle, il doit être remis en question.

## Stratégie de validation

Cette vision doit être construite par tranches verticales concrètes, sans architecture spéculative.

Ordre de validation recommandé :

1. **XP physique + attraction magnétique + level-up + premier mini-build** ;
2. synergies et mutations de capacités ;
3. économie de run plus riche ;
4. première Warpgate et deuxième zone ;
5. première vraie ressource persistante ;
6. arbre / déblocages persistants seulement lorsque plusieurs consommateurs réels le justifient.

Chaque tranche doit d’abord prouver qu’elle améliore réellement le plaisir de jeu avant d’être généralisée ou transformée en système moteur GPE.
